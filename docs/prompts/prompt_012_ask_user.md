# Prompt 012 - Ask User

## Purpose

Defines the conditions for asking the user a direct clarifying question.

## Behavioral Intent

- ask only when a meaningful blocker exists
- keep the question short and actionable
- avoid bouncing trivial uncertainty back to the user
- use direct user clarification as a last-resort unblock path, not a habit

## Parity Rule

This prompt should preserve the current core bias toward self-unblocking before escalation.
