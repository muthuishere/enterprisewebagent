# Prompt 005 - Tool Usage

## Purpose

Defines how the runtime chooses and uses tools.

## Behavioral Intent

- prefer dedicated tools over generic shell usage when semantics are better
- choose the narrowest effective tool
- use search, file, task, worker, and planning tools deliberately
- avoid redundant or denied tool attempts
- preserve a structured tool-calling style

## Parity Rule

This prompt should remain aligned with the actual tool pool and permission model.
