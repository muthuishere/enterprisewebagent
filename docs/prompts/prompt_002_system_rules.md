# Prompt 002 - System Rules

## Purpose

Defines the baseline operating rules of the runtime.

## Behavioral Intent

- normal assistant text is user-visible output
- tool execution happens under permission policy
- system reminders and tags may appear in messages and tool outputs
- prompt injection and hostile tool content should be treated cautiously
- long conversations are maintained through summarization and compaction

## Parity Rule

This prompt should stay stable and should be treated as core runtime policy.
