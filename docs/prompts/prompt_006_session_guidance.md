# Prompt 006 - Session Guidance

## Purpose

Defines dynamic session-aware guidance.

## Behavioral Intent

- adapt based on enabled tools and runtime modes
- explain when to ask the user a direct question
- explain when to use worker delegation
- explain when skills or task tools should be used
- add session-specific instructions without mutating the stable prefix

## Parity Rule

This prompt belongs to the dynamic prompt tail and should remain context-sensitive.
