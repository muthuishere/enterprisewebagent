# SCENARIOS

## Scenario 1: Interactive Web Session

The user opens the web UI, starts a session, sends a prompt, and watches streamed output plus tool activity in real time.

## Scenario 2: CLI Operator Flow

The user starts the Java CLI, connects to the hosted runtime, runs a task-oriented prompt, and streams the result in the terminal.

## Scenario 3: Long-Running Task

A session escalates a turn into a background task. The task continues in the hosted runtime and can be inspected from either CLI or web.

## Scenario 4: Configuration Change

The user changes provider/model configuration and both web and CLI flows continue using the same runtime contract.
